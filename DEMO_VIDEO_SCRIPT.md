# 3-minute demo video script and shot list

**0:00–0:20 — Problem and introduction**
Show the AccessPilot AI hero screen. Narrate: “Accessibility barriers often enter a product through small implementation decisions. AccessPilot AI helps teams identify actionable source-code issues before release, directly in their browser.”

**0:20–1:15 — Checkout analysis**
Scroll to the workspace. Choose Checkout form, press Analyze accessibility. Inspect the finding count and open the list. Narrate: “The app inspects HTML with deterministic rules for missing labels, image alternatives, button names, links, landmarks, and more. Every finding includes its evidence and an example fix.”

**1:15–1:50 — Explainable AI**
Point to issue priorities. Narrate: “Priority suggestions come from a small three-nearest-neighbors classifier using twelve explicitly disclosed synthetic examples. This ranking is educational, not a validated severity prediction. It cannot determine accessibility compliance.”

**1:50–2:20 — Second and clean examples**
Select News article and run the audit; then select Accessible page and run again. Narrate: “Different markup produces different findings. A clean automated scan is not proof of compliance: manual keyboard and screen-reader testing remains vital.”

**2:20–2:45 — Export and privacy**
Return to checkout and click JSON or Report. Narrate: “Exports are local. The application does not transmit source HTML, store cookies, or require an API key.”

**2:45–3:00 — Close**
Show the homepage. Narrate: “AccessPilot AI: design for everyone. Our next steps are broader rules, testing with accessibility practitioners, and real-world validation of ranking.”

**Recording requirement:** Capture the working application itself (not promotional mockups). Show the exported output. Record 1920×1080 or 1280×720 with readable text. Confirm permissions if the recording includes anything sensitive. Upload the completed video to an accessible host and add its URL to Devpost.
